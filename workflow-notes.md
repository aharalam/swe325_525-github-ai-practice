## Explanation of Workflow Concepts
- **Issues:** Used to track tasks, enhancements, bugs, or feature requests for a project.
- **Branches:** Isolated environments where you can write and test code without affecting the main/default codebase.
- **Commits:** Saved snapshots of changes made to files in the repository with descriptive messages explaining what changed.
- **Pull Requests:** A mechanism to notify team members about changes pushed to a branch so they can review, discuss, and merge them into the default branch.
- **Default Branch:** The primary production branch (usually `main`) that holds the clean, stable, deployment-ready history of the project.
