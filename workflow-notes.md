## GitHub Concepts

### Repository
A repository contains a project's files and their change history. For this lab, my repository holds the Markdown documentation and the history of changes made to it.

### Issue

An issue describes work to complete, its purpose, and the conditions that show it is finished. My issue contains the lab goal, acceptance criteria, and a checklist of tasks.

### Branch
A branch allows changes to be developed separately from the default branch. I am using feature/github-ai-workflow for the assignment changes.

### Commit
A commit records a snapshot of the repository's tracked files. Its message explains the change being recorded. Separate, meaningful commits make the history easier to understand and review.

### Pull Request

A pull request proposes merging changes from one branch into another. It allows the changes to be inspected, discussed, and revised before they are merged.

For this lab, the pull request will propose merging feature/github-ai-workflow into main.

### Default Branch

The default branch is the repository's primary branch. In this repository, it is main. After the pull request is merged, main will contain the completed documentation.
